# SMT2020 Dataset Attribution

Source: Kopp, D., Hassoun, M., Kalir, A., & Mönch, L. (2020).
"SMT2020 — A Semiconductor Manufacturing Testbed." IEEE Transactions on
Semiconductor Manufacturing.

Official distribution: https://p2schedgen.fernuni-hagen.de/index.php/downloads/simulation

These raw dataset files (routes, tool/station definitions, MTBF/MTTR
reliability calendars, WIP, orders) were obtained via the open research
artifact "PySCFabSim-revised" (Zenodo record 15088815, CC-licensed research
data), which redistributes the SMT2020 testbed files unmodified for
simulation research and reproduction.

This is a published academic benchmark representing realistic reentrant
semiconductor fab characteristics (LVHM = Low-Volume-High-Mix fab archetype).
It is NOT proprietary data from any specific real company's fab. All
simulation/optimization results derived from it in this project are
evidence-labeled as "published benchmark" — not "validated against a real
plant."
